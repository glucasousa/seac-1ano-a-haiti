# Quiz do Haiti 🇭🇹

> Quiz didático sobre a história, cultura e curiosidades do Haiti — a primeira república negra do mundo.

## Sobre o Projeto

Projeto educacional desenvolvido pelos alunos da **Turma do 1º A** do **Colégio José Bezerra de Menezes (JBM)**.

O quiz apresenta perguntas sobre:
- História da Revolução Haitiana
- Cultura e tradições
- Geografia e pontos turísticos
- Figuras históricas importantes

## Como Jogar

1. Abra o arquivo `index.html` no navegador
2. Clique em **JOGAR**
3. Escolha a dificuldade:
   - **Fácil**: 10 perguntas, 40s, +6s acerto / −4s erro, 10 pts
   - **Médio**: 10 perguntas, 30s, +5s acerto / −6s erro, 15 pts
   - **Difícil**: 10 perguntas, 22s, +4s acerto / −8s erro, 20 pts
4. Responda antes do tempo acabar!

## Funcionalidades

- Sistema de pontuação com bônus/penalidade de tempo
- Efeitos sonoros e música (Hino Nacional do Haiti)
- Sistema de combo para acertos consecutivos
- Cenário 32 bits inspirado na cultura haitiana
- Atalhos de teclado (1-4 para responder, Enter para continuar, M para música)

## Tecnologias

- HTML5
- CSS3 (animações, gradientes, clip-path)
- JavaScript (Web Audio API para sons e música)
